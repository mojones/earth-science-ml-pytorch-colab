# Plant seedlings: PyTorch classroom notebook

Open the [image-classification notebook in Google Colab](https://colab.research.google.com/github/mojones/earth-science-ml-pytorch-colab/blob/7e5ad19f8374ec0e45d5bd8f5e3ebc45db1c61b4/Deep%20learning%20and%20pytorch%20-%20Colab.ipynb), then select **Runtime → Change runtime type → GPU** and run cells from the top. This copy contains only the plant-image lesson, not the earlier penguin example. Its first code cell downloads the dataset with visible `curl` progress, then verifies and extracts it. The GPU is optional; without one, the image example uses fewer epochs. Colab provides `torch` and `torchvision` already.

The notebook automatically downloads the [1,200-image dataset archive](https://github.com/mojones/earth-science-ml-pytorch-colab/releases/download/v1.1/plant-seedlings-1200.zip) (85 MiB; 100 images per species) on a fresh runtime and checks its SHA-256 digest. `MAX_PER_CLASS = 10` is the default; try 20, 50 or 100 to experiment with training sizes (80% training, 20% validation). It is a classroom demonstration, not a benchmark. Validation images change with this setting, so the resulting accuracies are not a controlled comparison. The full course notebook and original 1.6 GB `plants/` folder are **not** included here. The matching source notebook lives in the course materials and defaults to CPU; switch the two commented device lines to use Colab/GPU.
